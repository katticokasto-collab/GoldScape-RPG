# GoldScape RPG 🎮

**MMORPG 3D para navegador inspirado en Old School RuneScape (OSRS)**

## 📋 Características

✅ **Jugabilidad Pura OSRS**
- Gráficos 3D low-poly limpios
- Cámara isométrica clásica
- Control Point-and-Click (clic en el suelo para mover)

✅ **Privacidad Total**
- 100% aplicación web local
- Cero telemetría
- Cero analíticas
- Cero monitoreo
- Cero anuncios
- Cero monetización

✅ **Arquitectura Limpia**
- Motor gráfico WebGL/Canvas 2D
- Sistema de control basado en clics
- Renderizador isométrico
- Sistema de cámara suave

## 🚀 Inicio Rápido

1. Clona el repositorio
2. Abre `index.html` en tu navegador
3. ¡A jugar!

No requiere instalación, servidor ni conexión a internet.

## 📁 Estructura del Proyecto

```
GoldScape-RPG/
├── index.html              # Página principal
├── styles.css              # Estilos de interfaz
└── engine/
    ├── mathUtils.js        # Utilidades matemáticas y conversiones isométricas
    ├── camera.js           # Sistema de cámara
    ├── renderer.js         # Renderizador 3D isométrico
    ├── inputHandler.js     # Manejo de entrada (clics)
    ├── world.js            # Sistema de mundo y objetos
    ├── player.js           # Sistema del jugador
    └── game.js             # Loop principal del juego
```

## 🎮 Controles

- **Clic izquierdo**: Mover a posición / Interactuar
- **Clic derecho**: Menú de contexto
- **Rueda de ratón**: Zoom cámara
- **Doble clic**: (próximamente)
